## Quick start (5 minutes)

The fastest path to seeing the pipeline produce something.

### Zero-key smoke test (no AI, no spend)

Proves the wiring without paying anything. Useful for validating a fresh checkout.

```bash
cp .env.example .env
make up                                      # postgres + redis + minio
make install                                 # uv sync + pnpm install
make migrate                                 # alembic upgrade head
make seed                                    # ai-productivity niche
make dev &                                   # api :8000, dashboard :3000, render :8787
make e2e-stub NICHE=ai-productivity          # uses placeholder script + skips assets
open http://localhost:3000/review            # click Approve
```

What this proves:
- docker stack reachable, schema applied, seed data present
- Reddit fetcher pulls live trends
- Approval gate works
- All three services boot

### Real pipeline run (needs API keys)

Add the keys you have. Each unlocks more of the pipeline:

| key set | extra capability |
|---|---|
| `ANTHROPIC_API_KEY` | Haiku scores trends; Sonnet writes scripts; cost estimate stamped on video |
| `+ ELEVENLABS_API_KEY` `+ PEXELS_API_KEY` `+ REPLICATE_API_TOKEN` | Real per-scene visuals + voiceover + word-level captions in MinIO |
| + render service running (`make dev` boots it) | Remotion renders 1080×1920 mp4 to `videos/{video_id}/output.mp4` |
| `+ YOUTUBE_OAUTH_*` (after manual approval) | `make publish VIDEO=<uuid>` uploads as unlisted to YouTube Shorts |

Plus, edit the seeded niche's `voice_id`:

```sql
-- via psql or any client
UPDATE niches
SET persona_json = jsonb_set(persona_json, '{voice_id}', '"YOUR_ELEVENLABS_VOICE_ID"')
WHERE slug = 'ai-productivity';
```

Then:

```bash
ANTHROPIC_API_KEY=sk-...  ELEVENLABS_API_KEY=...  \
PEXELS_API_KEY=...        REPLICATE_API_TOKEN=... \
make e2e-stub NICHE=ai-productivity
```

The script will print which keys it sees and what stages it ran. End state: a `pending_review` video at http://localhost:3000/review with all assets in MinIO at `videos/{video_id}/`.

## Concepts

| Object | Stored in | What it is |
|---|---|---|
| **Niche** | `niches` | A content lane (slug, brand persona, cost cap, daily quota). One channel per niche. |
| **Trend** | `trends` | A normalized item from Reddit / YouTube / Google Trends. Scored 1–10 by Haiku. |
| **Script** | `scripts` | A `ScriptDraft` JSON: hook + scenes + CTA. Generated by Sonnet. |
| **Asset** | `assets` | One image / audio / captions blob in S3, tied to a script. |
| **Video** | `videos` | The pipeline status holder. Has cost rollup + cost estimate + status. |
| **Publication** | `publications` | A successful upload to a platform with external_id. |
| **MetricSnapshot** | `metric_snapshots` | Views/CTR/retention pulled from platform analytics. |
| **CostEvent** | `cost_events` | Every paid action. Rolls up to `videos.cost_cents`. |

Pipeline:

```
trends   →  cluster + score  →  pick  →  script  →  assets  →  render  →  publish  →  metrics
 (Day 4)        (Day 4)         (Day 4)  (Phase 2) (Phase 3) (Phase 4) (Phase 5)  (Phase 6)
```

Status transitions on `videos.status`:

```
                                                        manual
pending_assets → pending_render → pending_review →    Approve / Reject    → approved → publishing → published
                                                        ↘ Reject ↘
                                                                  failed (failure_reason set)
```

## Settings reference (.env)

All settings load via `pydantic-settings` from `.env` (or process env). Defaults shown.

### Postgres / Redis / Storage

| key | default | notes |
|---|---|---|
| `DATABASE_URL` | `postgresql+psycopg://shortstack:shortstack@localhost:5432/shortstack` | psycopg v3 driver |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `shortstack` | only used by docker-compose |
| `REDIS_URL` | `redis://localhost:6379/0` | celery broker + result backend |
| `S3_ENDPOINT_URL` | `http://localhost:9000` | MinIO; swap to R2/S3 in prod |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | `shortstack` / `shortstack-dev-secret` | |
| `S3_BUCKET` | `shortstack` | created automatically by docker-compose `minio-init` |
| `S3_REGION` | `us-east-1` | required by signed URL generation |

### LLM

| key | default | notes |
|---|---|---|
| `ANTHROPIC_API_KEY` | (empty) | required for trend scoring + script generation + visual relevance grader |
| `SCRIPT_MODEL` | `claude-sonnet-4-6` | used by `generate_script` |
| `UTILITY_MODEL` | `claude-haiku-4-5` | used by trend cluster scorer + visual relevance grader |

System prompts are sent with `cache_control: ephemeral` so reprompts stay cheap. Cache write is paid once; reads ~10% of the input rate.

### TTS

| key | default | notes |
|---|---|---|
| `ELEVENLABS_API_KEY` | (empty) | required for voiceover |
| `ELEVENLABS_MODEL` | `eleven_turbo_v2_5` | ~3× cheaper than Multilingual v2; English-only |
| `OPENAI_API_KEY` | (empty) | reserved for OpenAI TTS fallback (not wired yet) |

The voice itself is **per-niche**, on `persona_json.voice_id`. Don't put a voice id in `.env`.

### Image generation

| key | default | notes |
|---|---|---|
| `PEXELS_API_KEY` | (empty) | tried first for non-hero scenes |
| `REPLICATE_API_TOKEN` | (empty) | Flux schnell for hero scene + low-relevance fallback |
| `FLUX_MODEL` | `black-forest-labs/flux-schnell` | wired through `Settings.flux_model`; the Replicate URL is built from this so you can pin a forked model without code changes |

### Trends

| key | default | notes |
|---|---|---|
| `REDDIT_USER_AGENT` | `shortstack/0.1` | Reddit's TOS requires a polite UA |
| `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | (empty) | reserved for PRAW migration; v0 uses public hot.json |
| `YOUTUBE_API_KEY` | (empty) | reserved for Phase 1 follow-up (YouTube Data API source) |

### Publishing (not wired in v0)

`YOUTUBE_OAUTH_*` — reserved for Phase 5.

### Render service

| key | default | notes |
|---|---|---|
| `RENDER_SERVICE_URL` | `http://localhost:8787` | worker calls this for Phase 4 render |

### Cost caps (per video)

| key | default | notes |
|---|---|---|
| `COST_SOFT_CAP_CENTS` | `75` | logged warn when video.cost_cents exceeds this |
| `COST_HARD_CAP_CENTS` | `100` | hard kill — task raises `CostCapExceeded`, video → failed |

The **per-niche** column `niches.cost_cap_cents` (default `100`) overrides the env default for that niche. The env vars are the global fallback used by tests and tools that don't have a niche in scope.

## Per-niche tuning

Most knobs live on `niches.persona_json` (a JSONB column shaped like the `NichePersona` Pydantic schema). Schema:

```json
{
  "brand": "Trending Tech: AI Productivity",
  "voice_id": "ELEVENLABS_VOICE_ID_HERE",
  "tone": "energetic, no-fluff, contrarian-friendly",
  "hook_styles": ["pattern_interrupt", "curiosity_gap", "contrarian"],
  "banned_topics": ["politics", "celebrity gossip"],
  "cta_template": "Follow for one AI workflow per day.",
  "subreddits": ["productivity", "getdisciplined", "ChatGPT", "artificial"]
}
```

| Field | What it does | When to change |
|---|---|---|
| `brand` | Channel display name; goes into video metadata in Phase 5 | Once per niche |
| `voice_id` | The ElevenLabs voice for this niche. **Must be set before TTS will run** — the placeholder `REPLACE_WITH_ELEVENLABS_VOICE_ID` raises a clear error. | Once per niche (rotation = new niche) |
| `tone` | Free-text used by Sonnet for voicing | If hooks feel off-brand |
| `hook_styles` | Restricts which hook styles the cached prompt allows. The default 3 cover most cases. | Rarely |
| `banned_topics` | Sonnet must avoid these | When you see drift you don't want |
| `cta_template` | Seed CTA. Sonnet rewrites it per video (≤12 words, same intent). | When the brand voice changes |
| `subreddits` | Reddit fetch sources for this niche. Min 1, no max — but more = more spend on Haiku scoring. | When trends look stale |

Top-level niche columns:

| Column | Default | What it does |
|---|---|---|
| `cost_cap_cents` | 100 | Hard cap per video. Pre-asset estimate above this rejects the script outright. |
| `daily_quota` | 3 | Target videos/day (Phase 9 honors this; v0 ignores). |

### Updating a niche

Until we add a UI, edit via SQL. Examples:

```sql
-- swap the voice
UPDATE niches
SET persona_json = jsonb_set(persona_json, '{voice_id}', '"abc123xyz"')
WHERE slug = 'ai-productivity';

-- raise the cost cap to $1.50/video
UPDATE niches SET cost_cap_cents = 150 WHERE slug = 'ai-productivity';

-- add a banned topic
UPDATE niches
SET persona_json = jsonb_set(persona_json, '{banned_topics}',
  (persona_json->'banned_topics') || '"crypto pumping"'::jsonb)
WHERE slug = 'ai-productivity';
```

### Adding a new niche

Two options:

1. **Edit the seed script** at `scripts/seed_niches.py` — add to `SEEDS`, then `make seed`. The seed is idempotent (skips slugs that already exist).
2. **Direct INSERT** if you don't want to redeploy:
   ```sql
   INSERT INTO niches (id, slug, name, persona_json, cost_cap_cents, daily_quota)
   VALUES (gen_random_uuid(), 'no-code-tools', 'No-Code Tools',
     '{"brand": "Trending Tech: No-Code", "voice_id": "...", "tone":"...","hook_styles":["pattern_interrupt"],"banned_topics":[],"cta_template":"Follow for weekly no-code stacks.","subreddits":["nocode","SideProject"]}'::jsonb,
     100, 3);
   ```

## Cost controls

The most important "knob". Defaults aim for ~$0.30–$0.45 per video.

### Two thresholds

```
soft warn (75¢)  →  log only, video continues
hard kill (varies, default 100¢)  →  raise CostCapExceeded, video → status=failed
```

Per-video rolling cost is tracked on `videos.cost_cents`. Each `record_*` call increments it; every producer immediately calls `check_video_cap` so the **next** charge is gated.

There's **also** a pre-asset estimate (`videos.cost_estimate_cents`) computed right after script generation. If it exceeds the cap, the video is created as `failed` and never enters `pending_assets` — saves 100% of the asset spend.

### Optimization stack (already on)

| Optimization | Saving | Where to tune |
|---|---|---|
| Pexels first (only fall back to Flux when relevance < 6/10) | ~70% of image cost | relevance threshold inside `tasks/visuals.py` (currently hardcoded to 6) |
| Hero scene (index 0) always uses Flux | quality on the only scene that matters | hardcoded; remove if you trust your stock library |
| Haiku for everything pre-script (clustering, scoring, image relevance) | Sonnet only writes scripts | model env var per task |
| Prompt caching on system prompts | ~90% of input-token cost on reprompts | `cache_system=True` is the default |
| ElevenLabs Turbo v2.5 (not Multilingual v2) | ~3× | `ELEVENLABS_MODEL` env var |
| Default scene count = 5, median scene 4s | fewer images + chars | scene count is in the script prompt, can be tuned |
| `faster-whisper` runs locally | $0 captions | model is `base.en`; swap to `small.en` if accuracy needs it |

### Optimization stack (not yet on, in TODO)

- **Asset reuse cache** keyed by `sha1(visual_prompt + style)` per niche — would zero out repeat-image spend
- **Soft-cap surfacing on the video row** — currently structlog only

### Where each cent goes (rough, $0.40 video)

| Item | Cost |
|---|---|
| Sonnet script (~2k input + 600 output, mostly cache hits after warm-up) | ~1¢ |
| Haiku trend cluster + relevance grading | ~1¢ |
| ElevenLabs Turbo voiceover (~250 chars) | ~7.5¢ |
| Flux schnell (1 hero + 1 fallback typically) | ~0.6¢ |
| Pexels (free) | 0 |
| faster-whisper (local CPU) | 0 |
| MinIO storage | negligible |
| **Total** | ~10¢ |

So the $0.75 soft / $1.00 hard caps leave **lots** of headroom for: more scenes, longer narration, more Flux fallbacks, or heavier models. Tighten the cap to push the system toward optimization.

## Operator workflows

### Run the trend pipeline manually

```bash
make trends-fetch    NICHE=ai-productivity   # Reddit /hot.json -> trends rows
make trends-cluster  NICHE=ai-productivity   # Haiku scores + cluster_id
make trends-pick     NICHE=ai-productivity   # consume top trend, returns its id
```

### Generate a script for a specific trend

```bash
uv run python -m shortstack_worker.cli scripts generate --trend-id <uuid>
# prints {script_id, video_id, estimate_cents, status, attempts, draft}
```

### Generate assets for a video

```bash
make assets VIDEO=<uuid>
# runs visuals (per scene, serial) -> tts -> captions
# on success flips pending_assets -> pending_render
```

### Approve / reject a video

Either the dashboard at `/review`, or the API:

```bash
curl -X POST http://localhost:8000/videos/<uuid>/approve
curl -X POST http://localhost:8000/videos/<uuid>/reject  # marks failed with failure_reason
```

### Re-run after partial failure

Every task is idempotent. If `generate_assets` failed on scene 3 of 5:

```bash
make assets VIDEO=<uuid>     # picks up at scene 3, doesn't redo 0/1/2
```

`generate_assets` also accepts `status='failed'` (it resets to `pending_assets` and retries).

## CLI reference

`uv run python -m shortstack_worker.cli ...`

```
trends
  fetch    --niche <slug>      Reddit /r/<sub>/hot.json into trends table
  cluster  --niche <slug>      Haiku cluster + score recent unconsumed trends
  pick     --niche <slug>      consume highest-scored trend, returns trend info

scripts
  generate --trend-id <uuid>   Sonnet script generation + reprompt + cost estimate
                               Creates Script + Video(pending_assets|failed)

assets
  generate --video-id <uuid>   visuals (per scene) + tts + captions
                               Idempotent on (script_id, scene_index|kind)
```

All commands run **inline** (`task.run(...)`) — no celery worker required. For background dispatch, use `task.delay(...)` from a Python REPL or schedule via beat.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `make migrate` fails with `connection refused` | postgres not up | `make up; sleep 2; make migrate` |
| `make seed` errors `niche table doesn't exist` | migrations not applied | `make migrate` |
| Dashboard shows `Failed to load` red panel | API not running on :8000 | `make dev`, check api logs |
| `make trends-cluster` raises `anthropic.AuthenticationError` | `ANTHROPIC_API_KEY` not set or wrong | check `.env` |
| `synthesize_voiceover` raises `voice_id not configured` | seeded niche still has the placeholder | run the SQL `UPDATE` from the Quick start section |
| `CostCapExceeded` raised on a video | rolling cost > niche.cost_cap_cents | either raise the cap or shorten the script |
| `make e2e-stub` says "ANTHROPIC_API_KEY missing — fallback…" | no key set | set the key, or accept the placeholder script for the demo |
| Pexels returns 401 | invalid `PEXELS_API_KEY` | regenerate at pexels.com |
| Replicate prediction stuck `starting` for >30s | model warm-up | timeout returns; task retries up to 3× |
| Whisper takes 60s+ for a 30s clip | first run loads `base.en` model (~150MB) | warmed in `lru_cache`, subsequent runs are fast |
| Worker prints "no module named shortstack_worker.tasks.assets" | added a task but didn't update `celery_app.py include=` | add it |

## Known limitations

- `videos.cost_cents` is an `Integer` column, so the rolling per-video cost
  rollup is rounded to the nearest cent on each `record_*` call. Sub-cent
  precision IS preserved on `cost_events.cost_cents` (Numeric), so reporting
  off `cost_events` is accurate; the cap-check off `videos.cost_cents` is
  accurate to ±0.5¢ per recorded event. Promoting `Video.cost_cents` to
  `Numeric` is tracked in `TODO.md`.
- `make e2e-stub` runs every step inline (no Celery worker). Real production
  traffic should go through `make worker` + beat.
- Reddit fetch uses public `/hot.json` (no OAuth). Rate-limited; PRAW
  migration tracked in `TODO.md`.
